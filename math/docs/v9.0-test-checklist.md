# 乘法工坊 V9.0 測試清單

基底：V8.3.1

## 1. 精準錯誤診斷
- [ ] 未完成：只框第一個需要補的格，不計答錯。
- [ ] 位值／左移錯誤：例如 23×14 的十位部分積寫成 23，提示十位起點，不直接顯示 230。
- [ ] 進位錯誤：只亮目前乘數、被乘數、進位與要修的答案格。
- [ ] 基本乘法錯誤：只提示目前乘法步驟。
- [ ] 欄位位置錯誤：數字正確但位置錯時，不判成基本乘法。
- [ ] 最後加法錯誤：部分積正確時，只提示最後相加區。
- [ ] 孩子模式不顯示英文錯誤代碼。
- [ ] 教師模式顯示中文「教師判讀」與實際值／預期值等資訊。
- [ ] 修改被提示的格子後，上一輪診斷高亮與訊息退場；再次按檢查才找下一個錯誤。

## 2. 繼續上次練習
- [ ] 進入自我挑戰後，重新進入乘法工坊可看到「上次練習」卡。
- [ ] 保存直式／拆解法／方格圖模式。
- [ ] 工作站練習保存工作站編號。
- [ ] 按「繼續練習」時產生乾淨的新題／新作答區，不恢復半成品答案。
- [ ] 已完成工作站時顯示「前往下一站」。
- [ ] 「重新選擇」可清除上次練習位置提示。
- [ ] 「重置設定」會清除上次練習位置，但不清除學習紀錄、徽章與工作站進度。

## 3. 輸入操作
- [ ] 直式輸入 1 個數字後自動移到下一個合理輸入格。
- [ ] 空白格按 Backspace 會回上一格並清除上一格。
- [ ] 有數字的格按 Backspace 只清目前格。
- [ ] 可直接點任意輸入格修改，不被系統強制拉回。
- [ ] Enter 可執行「檢查」。
- [ ] 練習區禁止 e、E、+、-、. 等非整數輸入。
- [ ] 焦點移動只做最小必要捲動。
- [ ] Toast 維持畫面上方，不遮主要輸入區。

## 4. 回歸測試
- [ ] V8.3.1 的首頁主圖不變。
- [ ] 乘法工坊入口圖不變。
- [ ] 乘法工坊上方內部配置圖不變。
- [ ] 獎勵訊息小精靈頭像正常。
- [ ] 1 位乘數粉紅／黃色提示正常。
- [ ] A/B、位數、速度、介面、資訊、音效、教學輔助仍可保存。
- [ ] 重置設定不清學習紀錄。
