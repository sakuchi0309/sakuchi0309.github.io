# 數學探險島／乘法工坊 V9.1 驗收清單

基底：V9.0.1

## A. 學習摘要

| ID | 測試 | 預期 |
|---|---|---|
| L-01 | 0 題紀錄 | 顯示「完成幾題後就會出現」，不做趨勢判斷 |
| L-02 | 1～4 題 | 顯示最近 N 題第一次答對率；不判定主要弱點 |
| L-03 | 5～9 題 | 顯示主要錯誤類型與文字型練習建議；不綁工作站 |
| L-04 | 10 題以上 | 以最近 5 題 vs 前 5 題顯示「更穩定／大致穩定／需要再練習」 |
| L-05 | 錯誤類型並列第一 | 顯示錯誤型態較分散，建議「綜合挑戰」 |
| L-06 | 最近 10 題皆第一次答對 | 顯示無明顯固定錯誤，建議「綜合挑戰」 |
| L-07 | 訂正成功 | 不回頭改變第一次答對率；以第一次檢查為統計基礎 |
| L-08 | 教師模式 | 顯示最近題數、正確數、錯誤統計、前5/最近5比較 |

練習建議對照：
- 基本乘法 → 九九乘法與單位數乘法
- 進位 → 單位數乘法進位
- 位值／左移 → 十位乘數與部分積左移
- 欄位位置 → 直式對位練習
- 最後加法 → 部分積相加
- 無明顯／分散 → 綜合挑戰
