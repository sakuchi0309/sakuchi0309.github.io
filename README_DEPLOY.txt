數學探險島平台 — 正式 GitHub Pages 發布包
================================================

你目前的 Repository：
  multiplication-adventure

建議改名為：
  username.github.io

其中 username 必須換成你的 GitHub 使用者名稱。

一、Repository 重新命名
-----------------------
GitHub Repository：
Settings -> General -> Repository name

將：
  multiplication-adventure

改成：
  username.github.io

例如 GitHub 使用者名稱若是 wisely：
  wisely.github.io

重新命名後，請確認本發布包的所有檔案位於 Repository 根目錄。

四、PWA 安裝
------------
請從：
  https://username.github.io/math/

使用 Safari 開啟，再：
  分享 -> 加入主畫面 -> 加入

不要從 multiplication 子頁單獨建立另一個 App。
數學探險島是一個平台型 PWA，未來乘法、除法與分數都由同一個主畫面入口進入。

五、PWA Scope
-------------
/math/service-worker.js
只控制：
  /math/

不會控制：
  /
  /about.html
  /projects.html
  /contact.html

Division Bay prototype v0.5
---------------------------

Division Bay V0.24
------------------
自我挑戰改為「正式直式除法」為主。

出題設定：
- 被除數位數：1 / 2 / 3 / 4
- 除數位數：1 / 2 / 3 / 4
- 最大數字：9999
- 題型：
  1. 隨機混合
  2. 剛好整除
  3. 最後有餘數
  4. 第一位不夠除
  5. 中途有餘
  6. 商中間有 0
  7. 多位數除數

- 除數位數 > 被除數位數：不自動更改設定，直接提示使用者調整。

- 商中間有 0 + 被除數少於 3 位：提示調整。

- 商必須填在對應位值的上方。

  - 乘回
  - 相減後剩下
  - 若還有下一位，填拉下後形成的新數
- 不再只填最後商與餘數。
- 最後一輪相減後留下的數，就是最後餘數。

錯誤診斷：
- 商位值錯
- 商中間 0 漏寫
- 乘回錯
- 相減錯
- 餘數 >= 除數
- 拉下錯
系統只先標出第一個發現的錯誤，讓孩子逐步修正。

答錯後同題回教：
- 直式：主要回教入口
- 餘數：有餘數題的規則確認
- 乘法驗證：整除題的驗證
- 拆解：適合拆解的整除題
全部都使用原來同一題。
